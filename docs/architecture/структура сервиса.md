# цель сервиса

Это экосистема корпоративных систем различного типа
1. HRM
2. CRM
3. Документооборот
4. Различные workflow( система закупок, участия в тендорах, подключения клиентов, судебная работа, юридическая работа, экономическая безопасность, комплаенс и т.д.)

основные микросервисы, которые позволят создать такую экосистему. Любая система будет собираться как набор настроенных под себя.

0. Сервис AprilHub - Рабочее место сотруднка, и единую точку входа для сотрудника, агрегирующую через BFF-слой все данные из корпоративных микросервисов
1. микросервис AprilWorkFlow - Он позволяет создавать, выполнять и отслеживать бизнес-процессы, описанные с помощью визуальных диаграмм( на ReactFlow). Как spiffworkflow, только на go и reactflow и без BPMN
2. микросервис AprilNFlow - предоставляет единый API и удобные инструменты, чтобы управлять отправкой сообщений по любым каналам из одного места(Унифицированный API, Гибкая автоматизация, Low-Code для всех, Готовый UI-компонент для других сервисов). Как novu, только на go и reactflow
3. микросервис AprilOrgFlow - Сервис представляет собой централизованное, версионируемое хранилище организационной структуры компании, поддерживающее гибкие модели иерархии (включая матричные и ролевые связи) и предоставляющее REST API для других внутренних сервисов (HRM, Active Directory, систем расчёта зарплат).Таким образом, сервис становится единой точкой правды для всех потребляющих систем, изолируя их от хаоса прямых интеграций с разными HR-источниками.
4. микросервис AprilProfil - Сервис представляет собой централизованное, версионируемое хранилище профилей сотрудников, подразделений и должностей, объединяющее HR-данные (ФИО, ставка, грейд, должностные инструкции) и информацию от службы безопасности (уровень доступа, особые отметки) в единой полиморфной модели. Он поддерживает версионирование каждого профиля с возможностью просмотра состояния на любой момент времени, полный аудит изменений и откат к предыдущим версиям. Через встроенные адаптеры сервис синхронизируется с внешними системами-источниками (HRIS, кадровое делопроизводство, AD, системы управления процессами), автоматически маппируя поля и разрешая конфликты. Единый REST API и event-стриминг делают его единой точкой правды для всех внутренних сервисов (доступы, расчёт зарплат, задачи, процессы), изолируя их от прямой интеграции с разрозненными источниками.
5. микросервис AprilEDC - Сервис представляет собой специализированный интеграционный коннектор (External Data Connector), который по расписанию или событию извлекает данные о вакансиях, резюме и компаниях с внешних порталов (HH, Фабрикант, LinkedIn и др.) через их API или парсинг, нормализует их к единой внутренней модели и передаёт в сервисы профилей и оргструктуры для обогащения и версионирования. Он не хранит мастер-данных сам, а выступает управляемым шлюзом-адаптером: обеспечивает контроль лимитов, кэширование, обработку ошибок и маппинг полей, изолируя остальные микросервисы от хаоса внешних форматов и протоколов. Благодаря такому подходу все внутренние системы получают актуальные рыночные данные из унифицированного источника, а интеграция с новым внешним порталом сводится к добавлению одного адаптера без изменения логики профилей и оргструктуры.
6. микросервис AprilReport - Сервис представляет собой централизованную платформу для построения отчетов и дашбордов, агрегирующую данные из всех внутренних микросервисов (организационная структура, профили, KPI, кадровый коннектор) и внешних систем через единый API-шлюз. Он выполняет предрасчёты и материализацию сложных агрегатов (текучесть, воронка найма, выполнение KPI по подразделениям), кэширует результаты и предоставляет как готовые аналитические срезы через REST API, так и данные для динамической визуализации на дашбордах с поддержкой фильтрации, срезов по времени и экспорта. Благодаря отдельному хранилищу для отчётов (OLAP или витрина данных) и механизмам инкрементального обновления, сервис разгружает операционные микросервисы от тяжёлых аналитических запросов и даёт единую точку получения всей аналитики для HRM-порталов, BI-инструментов и смежных систем.
