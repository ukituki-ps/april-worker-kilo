# Оптимизация бандла Hub Shell

## Базовая точка измерения

После первоначальной сборки размер каталога `dist/` составлял **~0.5 МБ** (грузится 1 МБ в браузере, gzip 346 КБ). Показатели превышают цель в 200 КБ gzipped для начальной загрузки.

## Меры оптимизации

1. **Code‑splitting** – все виджеты подключаются динамически через `React.lazy` (уже реализовано в `widgets.tsx`).
2. **Пакетизация** – добавлен плагин `vite-plugin-visualizer` для визуального анализа чанков.
3. **Пакет `bundle:report`** – выводит размер `dist/`.
4. **Сжатие** – рекомендуется включить Gzip/Brotli в Nginx.

## Примечания

- Пакет `@april/profile-ui-external` подключен через алиас, чтобы избежать конфликтов версий.
- При возникновении новых больших зависимостей следует пересмотреть manualChunks в `vite.config.ts`.

**Дальнейшие действия**: запустить `npm run build:analyze` и проанализировать отчёт для уменьшения размера.
