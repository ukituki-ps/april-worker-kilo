# Задача 038: реализация Sentry и error telemetry в AprilProfile (`april-profile-1`, внешняя)

## Мета
- **ID / ветка:** `038-aprilprofile-sentry-implementation`
- **Приоритет:** высокий
- **Тип:** [внешний репозиторий]
- **Связанные документы:**
  - результаты `033`, `034`, `036`
  - внешние `april-profile-1/tasks/<NNN-sentry-impl>/TASK.md`, `PLAN.md`, `REPORT.md`
  - интеграционные контракты AprilHub <-> AprilProfile

## Цель
Реализовать во внешнем репозитории `april-profile-1` Sentry/error telemetry для соответствующих UI/API слоёв с обязательной межрепозиторной корреляцией (`requestId/correlationId`) и двойным отчётом в `april-profile-1` и `april-worker`.

## Контекст для агента
- Выполнение происходит в `april-profile-1`, но результат должен быть синхронизирован с контуром AprilHub.
- Особое внимание на персональные данные в домене профиля и политику redaction.

## Входит в объём
- Внешняя реализация Sentry/error capture в `april-profile-1` по утверждённой архитектуре.
- Добавление/обновление обработчиков runtime и HTTP ошибок в релевантных слоях AprilProfile.
- Согласование тегов/полей событий с AprilHub для совместного triage.
- Обновление документации и runbook в `april-profile-1`.
- Запуск релевантных тестов в `april-profile-1`.
- Подготовка двойного отчёта:
  - внешний `REPORT.md` по задаче в `april-profile-1`,
  - локальный `tasks/038-aprilprofile-sentry-implementation/REPORT.md` в `april-worker` с ссылками.

## Не входит в объём
- Изменение бизнес-требований профиля, не связанных с наблюдаемостью ошибок.
- Внедрение в AprilHub (покрыто задачей `037`).

## Технические ограничения
- Не коммитить реальные DSN/секреты.
- Обязательная проверка redaction для доменных payload AprilProfile.
- Избегать breaking changes интеграционного контракта с AprilHub.

## Критерии готовности (acceptance)
- [ ] Во внешнем репозитории реализован и задокументирован Sentry/error telemetry контур.
- [ ] Поля корреляции согласованы с AprilHub и проверены на тестовом сценарии.
- [ ] Пройдены релевантные проверки/тесты `april-profile-1`.
- [ ] Подготовлен двойной отчёт со ссылками на PR/коммиты.
