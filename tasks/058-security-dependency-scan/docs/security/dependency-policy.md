# Политика зависимости (security) 

## Классификация
- **Critical** – исправляем сразу, иначе закрываем PR.
- **High** – исправляем в течение одной недели.
- **Medium** – исправляем в следующем спринте.
- **Low** – фиксируем в задаче.
