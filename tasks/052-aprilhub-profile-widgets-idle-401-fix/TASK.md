# 052 — 401 у виджетов профиля после простоя (dev)

## Цель

Устранить массовые `401` у виджетов на `#/app/profile/entities` после короткого простоя на стенде `dev.april.ukituki.tech`.

## Критерий приёмки

После деплоя: открыть список профилей / сущностей, подождать дольше TTL access token (или до срабатывания фонового refresh), убедиться что запросы к profile API не падают с `401` из‑за устаревшего Bearer в props.
